<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/icons/notezy.png" width="35"/> Notezy</h1>

<p align="center">
  Notezy é um aplicativo de bloco de notas leve para desktop, desenvolvido com Electron.js, com uma interface limpa e alto desempenho.
</p>

![NotezyDemo](https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/demos/notezy.png)

<img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ---------------------- | ------------------------------------------------ |
| ✨ Interface simples e intuitiva | Interface limpa e fácil de usar |
| 🔄 Desfazer e refazer | Desfaça ou refaça facilmente suas alterações recentes |
| ✂️ Recortar, copiar e colar | Gerencie e organize seus textos rapidamente |
| 🔍 Aumentar e diminuir zoom | Ajuste o tamanho do texto para uma visualização confortável |
| 📂 Abrir e salvar arquivos | Abra arquivos existentes e salve suas anotações com facilidade |

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Notezy.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd Notezy
```

### 3️⃣ Instalar as Dependências

```bash
npm install
```

### 4️⃣ Executar o Aplicativo

```bash
npm start
```
