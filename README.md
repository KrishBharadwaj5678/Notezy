<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/icons/notezy.png" width="35"/> Notezy</h1>

<p align="center">
  Notezy is a lightweight desktop notepad built with Electron.js, featuring a clean interface and fast performance.
</p>

![NotezyDemo](https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/demos/notezy.png)

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature | Description |
| ---------------------- | ------------------------------------------------ |
| ✨ Simple & Intuitive UI | Clean and easy-to-use interface |
| 🔄 Undo & Redo | Easily undo or redo your recent changes |
| ✂️ Cut, Copy & Paste | Quickly manage and organize your text |
| 🔍 Zoom In & Out | Adjust text size for comfortable viewing |
| 📂 Open & Save Files | Open existing files and save your notes with ease |

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Notezy.git
```

### 2️⃣ Navigate to the Project

```bash
cd Notezy
```

### 3️⃣  Install Dependencies  

```bash
npm install
```

### 4️⃣ Run the App  

```bash
npm start
```
