<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/icons/notezy.png" width="35"/> Notezy</h1>

<p align="center">
  Notezy это лёгкий настольный текстовый редактор, созданный с помощью Electron.js, с чистым интерфейсом и высокой производительностью.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ---------------------- | ------------------------------------------------ |
| ✨ Простой и интуитивный интерфейс | Чистый и удобный интерфейс |
| 🔄 Отмена и повтор действий | Легко отменяйте или повторяйте последние изменения |
| ✂️ Вырезать, копировать и вставить | Быстро управляйте и редактируйте текст |

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Notezy.git
````

### 2️⃣ Переход в каталог проекта

```bash
cd Notezy
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Запуск приложения

```bash
npm start
```
