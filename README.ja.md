<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/icons/notezy.png" width="35"/> Notezy</h1>

<p align="center">
  Notezyは、Electron.jsで開発された軽量なデスクトップ用メモ帳アプリです。シンプルで使いやすいインターフェースと高速なパフォーマンスを備えています。
</p>

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---------------------- | ------------------------------------------------ |
| ✨ シンプルで直感的なUI | クリーンで使いやすいインターフェース |
| 🔄 元に戻す・やり直す | 最近の変更を簡単に元に戻したり、やり直したりできます |
| ✂️ 切り取り・コピー・貼り付け | テキストをすばやく編集・整理できます |
| 🔍 ズームイン・ズームアウト | 見やすいようにテキストサイズを調整できます |
| 📂 ファイルを開く・保存 | 既存のファイルを開いたり、メモを簡単に保存したりできます |

## <img src="https://github.com/KrishBharadwaj5678/Notezy/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Notezy.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Notezy
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ アプリを起動

```bash
npm start
```
